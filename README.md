# muse-wifistory-entry

Entry for the make.fun competition [Tell a Whole Story in 32 Characters](https://make.fun/bounty/u-xvader-tell-a-whole-story-in-32-characters-f86dd978).

## The entry

> DadFellForThePrinceEmail

Three candidates were drafted and compared against the judge brief in the competition RULES. Selection reason: 'MomClickedThePopUpAgain' leaves the damage vague and 'ExStillPaysForThisWiFi' is mere smugness; the selected Wi-Fi name wins because it packs a character, a famous scam and a whole family disaster into 24 of the 32 characters, and a stranger in the network list gets the joke on the first read.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt` (sha256 ad38b9814b9be5917bb92250e63a1364ecb9bc7f5d9b29e65ab2dd2c7a016dc6).
